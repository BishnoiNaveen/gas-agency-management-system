PRIMARY APP (Web + API Server)
------------------------------
1. Install Node.js LTS from https://nodejs.org
2. Install XAMPP — start MySQL in XAMPP Control Panel
3. Create database "bishnoi_gas_service" in phpMyAdmin (if not done)
4. Double-click  RUN_GAMS_APP.bat  (auto-syncs to MySQL + opens app)
5. Browser opens http://localhost:3000
6. Login: Naveen Bishnoi / Bhambu2006
   Customer: customer / Bhambu2006
   More customers: ramesh_kumar, priya_sharma, etc. / Bhambu2006
7. Keep the "GAMS Server" window open while using the app

RE-LOAD SAMPLE DATA
-------------------
  cd gams_server
  npm run seed

OFFLINE ICONS (optional, once)
------------------------------
  cd gams_web
  npm install
  npm run vendor

ANDROID APK
-----------
1. Double-click  BUILD_APK.bat
2. Run  SETUP_GRADLE.bat  (first time)
3. cd gams_android && gradlew.bat assembleDebug
